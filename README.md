# School Management System

This project is a starter scaffold for a role-based school management system for Basic School and SHS.

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI + SQLAlchemy
- Database: PostgreSQL (configurable) with SQLite fallback for local development

## Run backend
1. cd backend
2. pip install -r requirements.txt
3. uvicorn app.main:app --reload

## Run frontend
Open frontend/index.html in a browser or serve the folder with a simple static server.
