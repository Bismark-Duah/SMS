# Workspace Guidelines & Rules

## Offline First Constraint
* The School Management System must function 100% offline. 
* Do not introduce external API dependencies or rely on internet access.
* Keep all database operations local (using SQLite for local development).
* Ensure frontend assets (JS, CSS, fonts) fail gracefully or are hosted locally when offline.
## Mandatory Pre-Implementation Discussion Rule
* ALWAYS discuss, clarify, and align with the user BEFORE writing or modifying any code.
* Do not write or execute code until explicit user confirmation is received.
